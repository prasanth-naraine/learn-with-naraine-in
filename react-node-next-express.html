Nodejs
  • sudo apt install nodejs && sudo apt install npm | Not a recommended way
  • Install using NVM [Node version manager] | recommended way
  • sudo apt update-upgrade -y
  • sudo apt install curl -y | client URL
  • curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash # Verify npm version:
  • \. "$HOME/.nvm/nvm.sh"
  • nvm install 26
  • node -v # Should print "v26.13.1".
  • npm -v # Should print "11.20.0".
  • Best trick is type nvm install 22/24/26 - it automatically install the desired version asked also change npm-npx versions
  • 26.13.1 node version has 11.20.0 npm-npx version | 24.22.3 node version has 11.19.1 npm-npx version | Easy switch between versions
Expressjs
  • npm install express mongodb cors dotenv | not a global installation | project specific installation
  • Expressjs handles api endpoints
  • Cors securely talks to backend from frontend
  • dotenv protects the credentials & port numbers
