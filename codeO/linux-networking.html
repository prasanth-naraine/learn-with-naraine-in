Introduction to Hacking
  • Hacking Definition - Gaining unauthorized access into a system without the knowledge of the target.
  • Are Hackers Criminals? - Yes in India, hackers are generally considered criminals. Hacking has both positive and negative sides, but the negative part is focused on most of the time, leading to lower awareness. Ethical hackers are called Information Security Experts, Cybersecurity Experts, or work in CyberCrime.
  • Hacking Types - White hat (defensive), Black hat (offensive), and Grey hat (acting depending on the situation).
  • Hacking Cycle - Reconnaissance/spying -> Scan target or deep scanning -> Gain access -> Maintain access using Trojans -> Covering tracks -> Repeat.
  • Port Scanning - The process of probing a port to find if it is open, closed, or unknown.
  • Trojans - Software that looks legitimate but still receives and shares data with its master.

Wine in Linux
  • Acronym - Wine Is Not an Emulator.
  • Purpose - Helps in running Windows applications on Linux and macOS.
  • Installation & Version - sudo apt update && sudo apt install wine, followed by checking version with wine --version (e.g., 6.0.3).
Scanning & Information Gathering
  • Gather Information - Use `nmap` to scan and find open ports and services.
  • Scan the Target - Use `nikto` to check for web vulnerabilities.
  • Get Subdomains and DNS - Use `amass` (OWASP) to keep records of subdomains.
  • Analyze Vulnerabilities - Use `sqlmap` to test and exploit SQL injection.
  • Exploit Vulnerabilities - Use `metasploit` or `armitage`.
  • Perform Forensic Analysis - Use `autopsy` or `hashcat`.
  • Generate Reports - Use `Dradis` or `metagoofil`.
