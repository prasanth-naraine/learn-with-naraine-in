Git, IDE, Remote

Git Overview
  • Git Definition - A version control tool that manages & stores different versions of files and code. It helps you work with others, track who did what, easily find the culprit, and undo mistakes.
  • Creator - Developed by Linus Torvalds, the legend who also created the Linux operating system.
  • Local Scope - Git works on your machine locally.
  • Remote Repositories - You can also use remote platforms like GitHub, GitLab, or Bitbucket to share your work.
Installation
  • Check Version - Open terminal and run: git --version
  • Install on Ubuntu/Debian - Run: sudo apt install git
Personal Access Token (PAT)
  • Commit Tracking - GitHub stores each commit associated with specific timestamps.
  • Repository Setup - Create a new private repository in your GitHub account.
  • Authentication - Personal Access Token (PAT) used for secure command-line authentication with GitHub.
Git Commands
  • git init - Initializes a new local repository.
  • git clone - Copies an existing remote repository to your local machine.
  • git status - Shows the status of your workspace and staging area.
  • git add - Adds changes to the staging area.
  • git commit - Commits the staged changes to the local repository.
  • git push - Pushes commits from your local repository to a remote repository.
  • git pull - Fetches and merges changes from a remote repository into your local branch.
  • git branch - Manages branches in your repository.
  • git checkout - Switches between branches or commits.
  • git merge - Merges changes from one branch into another.
  • git diff - Shows differences between commits, branches, or files.
  • git log - Displays a history of commits, including authors and dates.

Vs code Customization
  • Command Palette Shortcut - Ctrl + Shift + P to open the Command Palette, then search for `settings.json` (workspace option) to edit configurations.
  • The below code should be in json key-value pair one after other -> 
    { 
    "files.autoSave": "afterDelay" , 
    "workbench.colorTheme": "Default Light Modern" 
}
  • Color Theme - "workbench.colorTheme": "Default Light Modern" (Default theme).
  • Auto Save - "files.autoSave": "afterDelay" (Automatically saves files after a delay).
  • Activity Bar Location - "workbench.activityBar.location": "bottom" (Moves the sidebar placement to the bottom).
  • Editor Tabs - "workbench.editor.showTabs": "multiple" (Controls how many files can be shown with tabs).
  • Status Bar - "workbench.statusBar.visible": false (Hides bottom row with go-live server status).
  • Startup Editor - "workbench.startupEditor": "none" (Defines how the startup editor looks).
  • Tips Disabled - "workbench.tips.enabled": false (Disables startup tips).
  • Minimap - "editor.minimap.enabled": false (Hides side code preview length).
  • Breadcrumbs - "breadcrumbs.enabled": false (Hides file heading breadcrumbs).
  • Font Weight - "editor.fontWeight": "800" (Sets font thickness).
  • Font Family - "editor.fontFamily": "Tlwg Mono" (Sets the font typeface).
  • Font Size - "editor.fontSize": 13 (Sets font size in pixels).
  • Secondary Side Bar - "workbench.secondarySideBar.defaultVisibility": "hidden" (Hides secondary sidebar by default).
  • Format on Paste - "editor.formatOnPaste": true (Automatically formats code when pasted).
  • Format on Save - "editor.formatOnSave": true (Automatically formats code when saved).
  • Extension Auto-Update - "extensions.autoUpdate": false (Disables automatic extension updates).
